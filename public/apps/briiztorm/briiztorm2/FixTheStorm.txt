CELESTIA//OS — Comprehensive Implementation Plan

⸻

PHASE 0 — Foundational Stabilization

The system must first stop breaking, leaking, and confusing the user before any enhancements can land.

0.1 Error Boundaries & Fallbacks
	•	Wrap Three.js initialization in try/catch.
	•	Display modal when CDN fails; retry logic + offline fallback.
	•	Add global error logger for UI and rendering.

0.2 Memory & Cleanup
	•	Project deletion triggers:
	•	removal from scene
	•	disposal of geometries, materials, textures
	•	removal from internal arrays
	•	Replace per-project label canvas with reusable cached textures.

0.3 Core Refactors
	•	Extract project creation, HUD logic, grid logic into modules.
	•	Centralize state in a single state manager (projects, UI, camera, settings).
	•	Rewrite raycast handler so parent detection is predictable.

⸻

PHASE 1 — Persistence & Data Model Overhaul

1.1 Persistent Storage
	•	Implement autosave to localStorage.
	•	Schema:

{
  "projects": [...],
  "settings": { "cameraSpeed": ..., "theme": ... }

PHASE 2 — Navigation & Movement Rebuild

Goals:

	•	Reversible
	•	No parallax nausea

Tasks:

	•	W/S forward–back

2.2 Thruster System Rework
	•	Toggle transitions with easing.

2.3 Mobile Navigation

PHASE 5 — Graphics & Performance Renovation

5.1 Rendering Optimization
	•	Frustum culling for distant chrysalises
	•	LOD versions:
	•	Full mesh close up
	•	Simplified mesh at distance
	•	Sprite proxy at extreme distance
	•	Starfield instancing

5.2 Infinite Grid Fix
	•	Recalculate grid position based on camera modulo grid-size.
	•	Two-grid leapfrog kept—but rewritten with deterministic mathematics.

5.3 Label Rendering
	•	Use single offscreen canvas for all text → generate textures & cache.
	•	Depth-checked sprite material to avoid clipping.
	•	Billboard orientation updated in render loop.

5.4 Visual Polish
	•	New shaders for crystal cores (refraction, bloom)
	•	Real reflective floor using cube camera
	•	Adjustable fog density

5.5 Animation Improvements
	•	Smooth shard orbits
	•	Hover motion per project with seeded noise
	•	Crystal pulsing when selected
